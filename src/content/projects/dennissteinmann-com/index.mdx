Diese Website ist selbst ein Projekt – und wahrscheinlich das langlebigste von allen.

## Ziele

- **Eigentum statt Miete:** Alle Inhalte liegen auf meiner eigenen Domain.
- **Langform zuerst:** Artikel sind das Original, Social-Media-Posts die Ableitung.
- **Dauerhaft auffindbar:** Stabile URLs, strukturierte Daten, `llms.txt` für KI-Systeme.
- **Schnell & privat:** Statische Seiten, selbst gehostete Schriften, kein Tracking.

## Technik

Gebaut mit [Astro](https://astro.build) als statische Website. Inhalte sind MDX-Dateien im
Git-Repository, Bilder werden beim Build automatisch optimiert, Social-Media-Grafiken für
jeden Artikel automatisch erzeugt. Jeder Push auf `main` wird per GitHub Actions auf den
Server deployed.
